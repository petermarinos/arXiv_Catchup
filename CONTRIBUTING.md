# Contributing

## Scope

I am using this project as a way of improving my coding skills, so I would prefer issues suggesting improvements.
However, if there is something small, feel free to contribute!

## Development workflow

- Do not use USAian alternate spellings.
- Follow PEP 8 naming conventions (e.g. snake_case for functions, CapWords for classes).
- Add type hints on everything, check with PyLance and mypy.
- Use the black formatter and the PyLint linter

## Reporting issues

When reporting a bug, please include the catchup.log flie.
